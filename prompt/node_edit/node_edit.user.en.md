## Output DSL

```text
NODE <C>
K <M_or_continuous_range>
C <continuous_M_range> | <one-line audit reason>
TXT <compact factual record, not body prose>
O <M_or_continuous_range> | <one-line audit reason>
ENDNODE
```

- K requires no reason.
- C must be continuous and immediately followed by `TXT`; its audit reason is optional. `TXT` may contain only information already present in the range and should remain in the source language rather than creating an intermediate translation.
- O requires a short audit reason.
- Split non-continuous aliases across rows. Every input M must appear exactly once in K, C, or O.
- Reference only M aliases inside the current NODE. Do not invent aliases or fields, or reference across NODE blocks.
